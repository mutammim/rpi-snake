# Raspberry Pi Snake

I recently purchased a Raspberry Pi Zero 2 W and decided to program a game of Snake for it that utilizes my LCD HAT's screen and buttons! The specific HAT is [this model](https://www.waveshare.com/wiki/1.44inch_LCD_HAT) from Waveshare. You'll need to download the Python library from the SPI section to fulfill the "LCD_1in44" import.

It's pretty basic, but it has a snake (it's a square)...that eats food (that are also squares). The snake grows longer with each bite and can even travel across borders! Just don't eat your tail. One point per piece of food. Feel free to fiddle around with the code to your liking!
